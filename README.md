# KAM Desk — instaladores

Este repositorio solo contiene **releases**. El código vive en un repositorio privado aparte.

## Instalar en Windows

1. Abre la [última versión](https://github.com/cons0709/kam-desk-releases/releases/latest).
2. Descarga `KAM-Desk-Setup-<versión>.exe` y ejecútalo.
3. Windows mostrará «Windows protegió su PC» porque el instalador no está firmado: *Más información* → *Ejecutar de todas formas*.

Las actualizaciones siguientes llegan solas: la app las baja en segundo plano y se instalan al cerrarla.
